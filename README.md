# 🎵 Spotify Analytics Dashboard

An interactive **Spotify Analytics Dashboard** built using **Power BI**, **SQL**, and **DAX** to analyze track popularity, artists, albums, genres, explicit content, and audio features.

## 📊 Project Overview

This project transforms Spotify track data into an interactive dashboard that provides insights into music popularity and audio characteristics across different genres.

The dashboard allows users to explore:

- Track popularity
- Popularity by genre
- Top-performing tracks
- Explicit vs non-explicit content
- Track duration
- Audio features such as energy and danceability
- Artists and albums
- Popularity distribution

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze Spotify music data using SQL and Power BI
- Identify popular genres and tracks
- Understand the distribution of track popularity
- Analyze explicit and non-explicit content
- Compare audio features across genres
- Build an interactive and visually appealing dashboard
- Create meaningful KPIs and insights using DAX

---

## 🗂️ Dataset

The dataset contains Spotify track-level information including:

- Track ID
- Track Name
- Artist
- Album
- Popularity
- Track Genre
- Duration
- Explicit Content
- Danceability
- Energy
- Acousticness
- Instrumentalness
- Liveness
- Valence
- Tempo
- Loudness
- Speechiness
- Key
- Mode
- Time Signature

### Dataset Statistics

- **18,141 Tracks**
- **19 Genres**
- **5,777 Unique Artists**
- **9,502 Unique Albums**
- **32.76 Average Popularity**

> Note: Some metrics may vary slightly depending on Power BI transformations, filters, or the version of the dataset used.
